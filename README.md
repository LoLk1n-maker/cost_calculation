# ИИ-Технолог · Блок 4 — Расчёт себестоимости изделия

Программная реализация функциональной модели (IDEF0) расчёта плановой
себестоимости изделия по конструкторско-технологической документации.
Подробнее в файле практика_Аблякимов.docx


## Структура проекта = блоки IDEF0

Код повторяет диаграмму IDEF0: каждый модуль соответствует блоку декомпозиции A0.

| Модуль | Блок IDEF0 | Назначение |
|--------|-----------|------------|
| `parser_ai.py` | **A1** Анализ входных данных | Чтение спецификации и маршрута → структурированные данные. Точка подключения LLM. |
| `reference.py` | **A2** Сопоставление со справочниками | Подстановка цен, тарифов, ставок и нормативов. |
| `calculator.py` | **A3** Расчёт себестоимости | Ядро: A31 материалы · A32 операции · A33 накладные · A34 агрегация. |

| `models.py` | — | Структуры данных (Material, Operation, ProductData, CostResult). |

## Запуск

```bash
pip install openpyxl
python main.py
```

Результат — в папке `output/`:
- `kalkulyaciya.xlsx` — плановая калькуляция по статьям;
- `kalkulyaciya.json` — тот же результат структурированно (для смежных блоков / 1С).

## Исходные данные (`data/`)

- `specification.xlsx` — спецификация (BOM): наименование, марка, масса заготовки, масса детали.
- `route.xlsx` — технологический маршрут: операция, оборудование, норма времени, разряд рабочего.
- `spravochniki.json` — справочники: цены материалов и отходов, машино-час, тарифы по разрядам, страховые взносы, % накладных.

Чтобы посчитать своё изделие — замените строки в этих файлах.

## Методика расчёта

- **A31. Материальные затраты** = масса заготовки × цена/кг − возвратные отходы × цена отходов.
  Металлоёмкость = масса детали / масса заготовки.
- **A32. Затраты на операции** = Σ (время × тариф рабочего × (1 + страховые) + время × машино-час).
- **A33. Накладные расходы** = прямые затраты × % накладных.
- **A34. Итог** = материалы + операции + накладные, разложенные по статьям калькуляции.

Реализован **нормативный метод** калькулирования: себестоимость определяется
по техническим нормам до начала производства.

## Подключение AI-парсера (блок A1)

В MVP данные читаются из структурированного Excel. Для разбора «сырых»
документов (PDF, произвольный Excel) в `parser_ai.py` предусмотрена функция
`parse_with_llm()`. Пример интеграции с Anthropic API — в докстринге этой функции:
LLM получает текст документа и возвращает структурированный JSON с материалами
и операциями, который далее проходит по той же цепочке A2 → A3 → A4.
